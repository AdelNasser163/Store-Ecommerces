# توحيد الرئيسية بالكامل — feat/page-cohesion-all

التعديل مقيد بـ`body.pg-page`. الهيرو وشريط البراندات والهيدر وقالب product-card لم تتغير بنيتهم. ملفات hero-b.css وproduct-card.css وcatalog.js وبيانات المتجر لم تتغير؛ main.js أضيفت له ثماني ترجمات فقط. أبعاد الغلاف المشترك للهيدر/الصفحة تغيرت لتطبيق المحاذاة المطلوبة، مع الحفاظ على تصميم الهيرو الداخلي وخطوطه وألوانه.

## النظام المشترك

المصدر: hero-b.css وproduct-card.css وطبقة page-theme.css السابقة. متغيرات `--pg-*` في نهاية page-theme.css: #07111f / #0b192e / #10294a، أخضر #8bc34a، ليموني #bef264، سطح #f4f6f8، أبيض، حدود #e5e9ef، خصم #dc2626. عناوين وأرقام Bricolage Grotesque 800، نص Plus Jakarta Sans، وخط عربي Cairo/Tajawal. الحواف 28/24/16px وpill، زجاج rgba(15,30,47,.94) وحد #ffffff1c وblur 14px؛ حركة hover .2s ease، وظل الكارت 0 12px 36px #00000018.

عرض الغلاف الأقصى 1312px وهوامش 64px على الديسكتوب؛ عند 1440 الحواف الخارجية للهيدر والهيرو وكل الأقسام x64–1376. الحشو الداخلي 40px، فيبدأ محتوى الهيرو والأقسام والفوتر عند x104 تقريبًا؛ حشو الهيدر الداخلي يتبع نفس الحافة. على التابلت الهوامش 32px، والموبايل 20px مع استثناء غلاف الناف المدمج 10px للحفاظ على أزراره. الفوتر خلفيته ممتدة بعرض الشاشة وغلاف محتواه يتبع نفس المحاذاة.

العنوان القياسي: eyebrow أخضر 12px، H2 كحلي أو أبيض Bricolage 800 بحجم 28–38px وtracking -0.02em، وصف 15px ورابط pill عند وجود وجهة فعلية. المسافات 96px ديسكتوب و56px موبايل. المظهر الداكن له نفس التدرج والشبكة النقطية في Flash Deals والترقية والنشرة والفوتر؛ بقية الأقسام سطح/أبيض بالتناوب.

أعداد بطاقات الأقسام من نفس المنتجات وبنفس معنى dept/q، واختُبرت مقابل صفحة المنتجات: mobiles=9، laptop=3، audio=2، OLED=1، appliances=2، PlayStation=1. [تفاصيل الروابط والنتائج](links.json).

## قرارات وحدود محفوظة

- التكرار بين أقسام الهيرو الستة والشبكة السفلية باقٍ كما طُلب. الشبكة السفلية أغنى بالأوصاف والأعداد. أقترح لاحقًا الاكتفاء بالسفلية إذا تقرر اختصار الهيرو، ولم أحذف شيئًا الآن.
- لا يوجد مسار حقيقي لمشاهدة آراء إضافية؛ الثلاثة كلها ظاهرة، لذلك لم أضف View all وهميًا لهذا القسم. شرائط الثقة والنشرة لها أنماطها ووظائفها المناسبة بدل إضافة روابط بلا وجهة.
- توجد فقط روابط فعلية في الفوتر. Careers/Press/Privacy/Terms/Help/Returns/Tracking/Shipping والأيقونات الاجتماعية تبقى نصوصًا أو رموزًا حتى تتوفر وجهاتها. لم أعدّل shared-site-footer.js، والتغيير يخص الرئيسية فقط ويحافظ على ترجمة النصوص.
- التبويبات تحتفظ بفلترة main.js الحالية التي تشمل كروت الرئيسية كلها؛ لم أغيّر المنطق الممنوع. أضيفت حركة للنتيجة وحالة خالية داخل Featured إذا كانت نتائج الفئة في Flash Deals فقط.
- النشرة كانت input + button دون form submission أو خدمة إرسال. حافظت على ذلك ولم أختلق اشتراكًا أو قسيمة ناجحة. تفعيلها يحتاج اختيار الخدمة وربطها وسياسة القسائم.
- النصوص والادعاءات الموجودة مسبقًا في الهيرو والترقية والنشرة لم تتغير. أضفت أوصاف أقسام عامة فقط وترجمتها، دون ادعاءات تسويقية جديدة.

## التحقق

- [results.json](results.json): 6 حالات en/ar ×1440/820/390، وبعد تمرير حقيقي لا كروت أو عناوين باهتة/مخفية، ولا سكرول أفقي؛ السلة والعداد والدرج والمفضلة والتبويبات واللغة وحقل البريد كما كانت. لا أخطاء JS في الحالات الست.
- Reduced-motion، طباعة، IntersectionObserver لا يرسل callbacks، حجب GSAP، وحجب islands: المحتوى ظاهر. آلية كشف الحركة في fx.js أصبحت لا تخفي محتوى الرئيسية قبل وصول callback، مع مهلة تنظيف، ودعم beforeprint/reduced-motion.
- فتح accessories/product/checkout/auth بنجاح وعدم وجود pg-page فيها. [source-checks.json](source-checks.json) يثبت بقاء ملفات التصميم المرجعي والكارت وcatalog والمنطق السابق كما كانت، وأن main.js ترجمات فقط وأن الـCSS القديم قبل كتلة pg لم يتغير.
- [interactions.json](interactions.json): بحث الهيدر إلى صفحة المنتجات، قائمة الموبايل، تبديل اللغة وترجمة وصف الأقسام ونصوص الفوتر.
- [links.json](links.json): 26 وجهة محلية تعيد 200، والأقسام الستة تفتح الفلاتر الصحيحة وتطابق أعدادها. grep عن href="#" وjavascript: في index.html نتيجته صفر؛ والفحص نفسه للـDOM بعد توليد الفوتر صفر.
- [contrast.json](contrast.json): أزواج النصوص الصغيرة الفعلية 4.83:1 إلى13.48:1؛ الرمادي على الأبيض 6.31:1، والنص الفاتح على الكحلي 11.16:1. هذا فحص ألوان الرموز الأساسية، وليس مسحًا آليًا لكل بكسل في الصور.
- npm run build:fx وnode --check وCSS parsing نجحت؛ لا مكتبات أو صور جديدة. نسخة rb-islands.js المجمعة محدثة.

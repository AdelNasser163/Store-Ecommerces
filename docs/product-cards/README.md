# توحيد كروت المنتجات

## الفروق المسجلة قبل التنفيذ

| العنصر | الرئيسية | صفحة المنتجات |
|---|---|---|
| المصدر | HTML ثابت قديم يستبدله catalog.js | بيانات وفلاتر js/products-page.js |
| البنية وقت التشغيل | shared-product-card.js: article.product-card.catalog-product-card | نفس الدالة والبنية |
| العنوان والصورة | رابطان في النسخة المولدة؛ h3 وصورة بلا رابط في القالب الثابت | روابط من النسخة المشتركة |
| الشارات | القالب الثابت فيه Official Warranty وNew Arrival؛ المولد يعرض الخصم ونفاد المخزون | الخصم ونفاد المخزون |
| التقييم | تقييم وعدد مراجعات | نفس العرض |
| السعر | سعر وسعر قديم ومقدار توفير | نفس العرض مع getEffectivePrice |
| المخزون | القالب الثابت claimed وأعداد ثابتة؛ المولد يعرض متوفر/غير متوفر | متوفر/غير متوفر |
| السلة | إضافة مباشرة | إضافة ثم product-stepper مع زيادة/تقليل الكمية |
| المفضلة | data-toggle-wishlist وdata-wish | نفس الخصائص، مع تحديث جزئي للكارت |
| Flash Deals | شريط claimed في القالب الثابت يختفي عند استبداله؛ countdown للعروض المؤقتة | دون إضافات خاصة |
| الشبكة والحركة | 5 أعمدة للفلاش و4 للمميزة | أوضاع 3/4/5 أعمدة؛ CSS مشترك يمنع hover lift/zoom |

## Tokens من الكود الفعلي

- `#8bc34a` للتفاعل، `#0b192e` للكحلي، `#bef264` لسعر النسخة الداكنة، `#dc2626` لشارة الخصم.
- Bricolage Grotesque للعناوين/الأسعار، Plus Jakarta Sans للنصوص؛ Cairo/Tajawal مع Segoe UI/Tahoma للعربية عند غياب الخط الخارجي.
- الهيرو: كارت رئيسي 28px، كروت جانبية 24px، صور 20px/16px؛ أزرار 999px.
- الهيدر النهائي: `rgba(15,30,47,.94)`، حدود `#ffffff1c`، blur(14px)، shadow `0 12px 36px #00000018`.
- زجاج الهيرو: `#ffffff1f` مع حدود `#ffffff40` وblur(10px).
- hover الهيدر: `.2s`، easing الافتراضي `ease` لأن transition لا يحدد غيره.

المتغيرات `--hb-*` في product-card.css محصورة داخل .hb-card/.hb-card-grid، ولا تغيّر tokens الهيدر أو الهيرو.

## ما تغيّر

- منشئ واحد في `js/product-card.js` تحت API `AlMumezProductCard.render` الذي تستخدمه الصفحتان. حُذف shared-product-card.js القديم، واستُبدلت مراجع تحميله أيضًا في product/about/blog/contact حتى لا يتبقى منشئ آخر أو رابط مكسور.
- حُذف HTML المنتجات الثابت القديم في الرئيسية، والشبكتان تحملان data-products-section. بإذن المستخدم تغيّر **اكتشاف الشبكة فقط** في catalog.js.
- تنسيق موحّد في product-card.css؛ كروت فاتحة فعلية للصفحات الفاتحة ودعم hb-card--dark للسكاشن الداكنة. لا يتم تحويل أي قسم إلى داكن تلقائيًا.
- بقيت data-add-to-cart وdata-toggle-wishlist وdata-add وdata-wish وproduct-card-actions وproduct-wish وعناصر كمية السلة. بعض كلاسات الربط القديمة موجودة عمدًا لتوافق المنطق الحالي، لكنها ليست منشئًا أو قالبًا منفصلًا.
- بقيت معلومات البراند والقسم والتقييم والمراجعات والمخزون والتوصيل والسعر القديم والتوفير؛ زر التفاصيل صار سهمًا بدل العين، مع نفس رابط المنتج. الصورة والعنوان رابطان حقيقيان.
- شريط claimed يستند إلى getEffectivePrice وبيانات العرض، وليس نسب HTML الثابتة القديمة. يُعرض بنفس الطريقة في الصفحتين للمنتجات المؤهلة، وكذلك العدّاد للعروض المحددة بوقت. انتهاء العرض يعيد تسعير الكارت فورًا.
- تنسيق العملة داخل الكارت صار واحدًا في الصفحتين، بدل اختلاف موضع EGP بينهما. القيم المالية والخصومات من المصدر الفعلي نفسه.
- الشبكة الافتراضية 4 / 3 / 2 أعمدة. اختيارات المستخدم اليدوية القديمة 3 أو 5 أعمدة على الديسكتوب ما زالت تعمل؛ التابلت والموبايل يحتفظان بـ3 و2.
- أول صف في صفحة المنتجات eager بأبعاد ثابتة؛ الرئيسية تحت الـ fold تستخدم lazy. img واحد داخل كل كارت؛ SVG القلب لا يضيف صورًا أو مكتبات.
- إضافة ترجمات في main.js. وبإذن منفصل من المستخدم، صُحّح مصدر حساب السعر في مساري إضافة السلة والمفضلة ليستخدم المنتج الأصلي من StoreProducts.read()؛ هذا يمنع خطأ المراجع الدائرية الناتج عن احتفاظ main.js بعناصر DOM التي أضاف لها GSAP بياناته. لم يتغير حساب السعر أو المخزون أو كميات السلة.
- تعديلات fx.js محصورة في selectors الكروت والدخول وطيران الصورة. الهيدر والهيرو وكودهما لم يتغيروا، كما تثبت source-checks.json. لم تتغير style.css أو products-page.css أو data/* أو منطق checkout أو ملفات admin.

## التحقق والأدلة

- Chrome + Playwright على سيرفر static محلي؛ 1440 و390، بالإنجليزية والعربية، للصفحتين. 820 تم اختباره أيضًا لـ3 أعمدة.
- الإضافة للسلة والمفضلة وإزالتها من الصفحتين، أزرار زيادة/تقليل الكمية بصفحة المنتجات، وجود طيران الصورة، وروابط المنتج: ناجحة.
- اختبار اللغة بعد الرسم، وزر اللغة الحقيقي بكل صفحة، والفلترة/الترتيب وفلاتر الرئيسية: ناجحة.
- بعد المرور على الصفحة كلها: صفر كروت مخفية؛ صفر أخطاء JavaScript في الحالات المختبرة؛ صفر سكرول أفقي.
- prefers-reduced-motion: لا hover lift/zoom ولا دخول متحرك، والكارت ظاهر. تعطيل GSAP بالكامل: كل الكروت ظاهرة.
- النسخة الداكنة ونفاد المخزون وتعطيل زر الشراء واختبار انتهاء عرض مؤقت: ناجحة، ببيانات متصفح معزولة لم تُحفظ في ملفات الموقع.
- product.html وcheckout.html وauth.html تفتح دون أخطاء JavaScript في المسار المختبر. هذا ليس اختبارًا كاملًا لإتمام الدفع أو تسجيل الدخول.
- node --check ناجح على الملفات المعدلة. فحص المصدر لا يجد كروت Flash/Grid القديمة أو product-card-media أو مراجع shared-product-card في صفحتي الرئيسية والمنتجات.

لقطات `*-page.png` هي المقاسات الطبيعية داخل الصفحتين. المقارنات `comparison-*.png` تعرض نفس المنتج بعرض موحّد (280px للديسكتوب، 172px للموبايل) لأن صفحة المنتجات تحتوي sidebar فتختلف مساحة الشبكة عن الرئيسية. في المقارنة فقط تم إلغاء تمدد الكارت إلى ارتفاع صف الجيران وإخفاء الإشعارات وأزرار الصفحة العائمة، حتى لا تغطي الكارت. المحتوى والارتفاع والخطوط متطابقة عند هذا العرض؛ اختلاف الإحداثيات قد يغيّر تنعيم الحروف ببكسلات طفيفة.

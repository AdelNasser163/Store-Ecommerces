# توحيد صفحة المنتجات

هذه المرحلة تخص accessories.html فقط. لم يتم تفعيل التنسيق في صفحة أخرى أو تعديل الرئيسية والهيرو وقالب الكارت أو منطق السلة والمنتجات.

## التغييرات

| العنصر | قبل | بعد |
| --- | --- | --- |
| الناف | صفوف بيضاء منفصلة | الشريط الزجاجي العائم من hero-b.css، نفس أيقونة المفضلة، ترتيب روابط الرئيسية، بحث حقيقي وعدد السلة وإجماليها |
| الفوتر | التنسيق القديم | نفس page-theme.css والمكوّن المشترك المستخدم في الرئيسية |
| عنوان الصفحة | عنوان منفصل | سطح فاتح بحواف 24px وخط وألوان الهوية |
| الفلاتر والأدوات | ألوان وحواف متفرقة | كحلي وأخضر، حدود خفيفة، أزرار pill وحالة focus واضحة |
| الكروت | القالب الموحد بالفعل | القالب نفسه دون تعديله، شبكة متوازنة تعطي الكارت عرضًا يقارب كارت الرئيسية |

الافتراضي على الديسكتوب 3 كروت بجانب عمود الفلاتر، و3 على التابلت، و2 على الموبايل. أوضاع العرض الواسع/المتوازن/المضغوط باقية؛ أسماء الإتاحة تصف كثافة العرض بدل عدد أعمدة لا يصح على كل مقاس. ارتفاع الكروت متساوٍ داخل الصف، ويظل المحتوى كاملًا.

أضيف ملف catalog-theme.css وتهيئة اختيارية js/site-chrome-theme.js. التهيئة تزيّن عناصر الهيدر الموجودة دون إعادة إنشائها أو فقدان أحداثها، وتعمل فقط عند وجود catalog-theme. ملفات التنسيق الأساسية المشتركة للهيرو والكروت لم تتغير.

روابط الفوتر غير المربوطة بصفحات فعلية وإظهار Dashboard احتفظا بسلوك المكوّن الحالي؛ لم أضف خدمة أو أغيّر صلاحيات.

## التحقق

لقطات قبل وبعد باللغتين: 1440 و390، وبعد على 820 أيضًا. ملفات after مأخوذة بعد التمرير عبر الصفحة لتشغيل reveals. نتائج التحقق الآلي في results.json: البحث، الفرز، لوحة الفلاتر، السلة والعداد والدرج، المفضلة، قائمة الموبايل، تبديل اللغة، عدم وجود سكرول أفقي أو كروت مخفية بعد التمرير، وتقليل الحركة.

التعديلات الموجودة مسبقًا في المشروع محفوظة خارج commit هذه المرحلة. لم يتم push أو البدء في صفحة جديدة.

رصد الاختبار أثناء إعادة تحميل اللغة الاستثناء العابر `Transition was skipped` دون stack من كود التطبيق في بعض الجلسات؛ مسجل كما هو في النتائج، ولم يُحسب كنجاح لاختبار خلو المتصفح تمامًا من الاستثناءات. بقية فحوص الوظائف مستقلة عنه.

# تطوير الكروت المشتركة

- Flash Deals يستخدم مقاس أربعة كروت على الديسكتوب، وثلاثة على التابلت، واثنين على الموبايل، مثل Featured. المنتجات الخمسة باقية في صف يمكن تمريره أفقيًا باللمس أو لوحة المفاتيح، دون تمرير أفقي للصفحة أو تصغير الكروت لاستيعاب الخمسة.
- قالب الكارت المشترك وصفحات الرئيسية والمنتجات والمنتج تستخدم نفس الإصدار الجديد؛ لم يتغير الهيدر أو الهيرو أو منطق السلة والمفضلة.
- حدود أنعم، ظل على طبقتين، سطح فاتح متدرج، وزجاج كحلي متدرج للنسخة الداكنة. نفس أخضر التفاعل والكحلي وخطوط الهوية والحواف الدائرية.
- فاصل خفيف قبل السعر، مساحات ثابتة للعناوين والأسعار وبيانات العرض، وأزرار تفاصيل ومفضلة مستديرة وحالة focus واضحة. تفاصيل العرض الحقيقية محفوظة داخل مساحة مشتركة بدل اختلاف ارتفاع الكارت عند ظهورها. العناوين لا تُقص؛ النصوص الأطول يمكن أن تزيد ارتفاع الصف عند الحاجة.
- احترام prefers-reduced-motion، والإبقاء على صور المنتجات الأصلية وروابطها وأبعادها.
- صف العروض نفسه يستثني إخفاء كل كارت بواسطة reveals حتى تظل المنتجات خارج إطار السحب قابلة للوصول بالكيبورد؛ حركة العنوان والـ hover باقية. تم اختبار الوصول للكارت الخامس بالتركيز في العربي والإنجليزي.

## التحقق

results.json يسجل مقارنة أبعاد كارت Flash بكارت Featured بالإنجليزي والعربي على 1440 و820 و390. فروق العرض والارتفاع أقل من بكسلين بسبب حد الباند الداكن. فُحصت الإضافة للسلة والمفضلة، رابط تفاصيل المنتج، عدم وجود سكرول أفقي للصفحة، وتقليل الحركة. اللقطات flash/featured/catalog توضح الستايل بكل المقاسات. أُخفي الهيدر مؤقتًا وقت التقاط مقطع القسم فقط حتى لا يغطي الكروت في الصورة؛ لا يغير ذلك ملفات الموقع.

تعديلات العمل السابقة محفوظة خارج commit هذه المرحلة. لم يتم push.

## Tokens المرجعية

من hero-b.css وproduct-card.css: #07111f، #0b192e، #8bc34a، #bef264، #dc2626؛ زجاج الهيدر rgba(15,30,47,.94) وحد #ffffff1c وblur(14px)، ظل 0 12px 36px #00000018؛ 24px للكروت و16px للأجزاء الداخلية و999px للـ pill؛ Bricolage Grotesque 800 وPlus Jakarta Sans، مع بديل العربية الموجود؛ hover .2s وease. القيم المكملة المحددة في الطلب: #10294a و#f4f6f8 و#e5e9ef، ومسافة أقسام 96px/56px.

## النتيجة والقرارات

- ملف واحد جديد page-theme.css للثيم، محصور في body.pt-page بالصفحة الرئيسية. لم يتغير ستايل الهيدر أو الهيرو أو الكارت أو قالب الكارت. تفعيل hb-card--dark في Flash Deals يتم عبر الخيار الموجود أصلًا في منشئ الكارت؛ الشبكة تستخدم وضع grid-5 الموجود للديسكتوب كي لا يبقى الكارت الخامس في صف داكن شبه فارغ، و3/2 للتابلت/الموبايل.
- أُضيفت خلفية انتقالية بطول نحو 240px أسفل الهيرو. شريط الثقة له margin سالب 48px داخل امتداد الخلفية، لا فوق شريط البراندات؛ هذا يحافظ على الهيرو كما هو ولا يغطي محتواه.
- الفواصل القياسية 96px للديسكتوب و56px للموبايل. باندان كاملان داكنان: Flash Deals والنشرة؛ بالإضافة للفوتر المطلوب وكارت PC الداكن الصغير. الباقي أسطح بيضاء وفاتحة مع توهجات ثابتة ضعيفة.
- بقية المحتوى والفوتر يحاذيان **حواف محتوى الهيرو الفعلية**: عند 1440 تبدأ الحافة من x=152، وعند 820 من x=110 لأن عمود الهيرو يتوسط بعرض 600px، وعند 390 من x=20. الهيدر احتفظ بعرضه الأصلي. لم أفرض هامش 64px حرفيًا على العناصر المحمية، لأن ذلك كان سيخالف شرط عدم تغيير الهيدر/الهيرو؛ 64px محفوظة كمتغير للهامش القياسي والفوتر، مع مراعاة حدود المحتوى الحالية.
- نمط العناوين eyebrow + H2 Bricolage 800 + وصف + View all حيث توجد وجهة حقيقية. روابط View all بالإحصاءات والعروض التعريفية تفتح الكتالوج. قسم الآراء يعرض المراجعات الثلاث الموجودة بالكامل؛ لا توجد صفحة آراء منفصلة للرابط. الأزرار الجديدة pill، وكل focus/hover محصور في مكونات الثيم الجديد.
- **التكرار مقصود ولم يُحذف:** بقيت الأقسام الستة في الهيرو والسكشن السفلي. السكشن السفلي أغنى وبأعداد فعلية وفق نفس dept/q الذي يفتحه كل رابط. الاقتراح المستقبلي: حذف شريط الأقسام الصغير من الهيرو والاحتفاظ بالسكشن الغني، إذا وافقت لاحقًا على تعديل الهيرو.
- **قرار الأرقام:** استبدلت 24h و14-day في CountUp بعدد المنتجات والبراندات وأقسام الكتالوج والعروض النشطة من StoreProducts.read()/getEffectivePrice(). لا أرقام ثابتة أو + أو ادعاء اعتماد جديد. عدد أقسام الكتالوج هو عدد category IDs في البيانات، وليس عدد مجموعات التصفح الستة، التي يستخدم بعضها بحثًا داخل التصنيف الأوسع. تمت إضافة نسخة عرض ثابتة من نفس البيانات إذا فشل تحميل React Bits.
- عناوين الأقسام والآراء مترجمة بالكامل. الآراء الثلاثة وأسماؤها ومحتوى العرضين الترويجيين من الصفحة القديمة، دون اختراع مراجعات أو ادعاءات جديدة.
- أزيل العدّاد الثابت 08h:42m:19s من عنوان Flash؛ لم يكن مربوطًا بموعد عرض. عدادات الكروت الحقيقية التي يدعمها المنشئ بقيت كما هي وتظهر عندما يوجد endsAt.
- تغيرت روابط كانت href="#": View all للعروض → accessories.html?sale=1، وكل المنتجات → accessories.html، Configure Setup → contact.html للاستفسار عن التجميع، وExplore Bundles → قسم الأجهزة المنزلية. لا يوجد محرر تجميع أو صفحة باقات مستقلة جديدة. لم يُضف منطق سلة أو خصومات.
- **النشرة تحتاج قرارًا لاحقًا:** الكود الأصلي لم يحتوِ form أو معالج إرسال/خدمة بريدية، بل input وزر Claim Voucher فقط. بقي سلوكهما كما هو، مع تحسين العرض والتسمية والتحقق الأصلي لنوع email؛ لم أختلق نجاح اشتراك أو قسيمة. تفعيل الاشتراك فعلًا يحتاج تحديد خدمة/endpoint وسياسة القسيمة. روابط الخدمات/السوشيال غير المهيأة في الفوتر المشترك بقيت على سلوكها الأصلي.

## التحقق

- لقطات full-page قبل وبعد بالإنجليزية والعربية، 1440 و390؛ واختبارات إضافية عند 820. نسخ 390 المعروضة مقصوصة إلى عرض الـ viewport المطلوب، والأصل الخام من المتصفح محفوظ أيضًا بلاحقة -browser، لأنه قد يشمل رسم عناصر خارج الشاشة.
- كل حالات المقاسات الستة: صفر أخطاء JavaScript، بلا سكرول أفقي، وكل الكروت والعناوين تظهر بعد المرور على الصفحة. الخلفيات والمسافات والعناوين والفوتر راجعتها بصريًا.
- مقارنة geometry/ألوان/خطوط الهيدر والهيرو مع HTML القديم في نفس المتصفح نجحت. وفحص المصدر يثبت تطابق hero-b.css وproduct-card.css وjs/product-card.js وmarkup الهيدر والهيرو؛ التعديل في src-islands محصور في Stats، وفي main.js محصور في إضافة الترجمات.
- السلة والمفضلة وطيران الصورة وتبويبات Featured وتغيير اللغة تعمل. الأقسام الستة تفتح فلاتر فعلية، وأعداد نتائجها تطابق الأعداد المعروضة.
- prefers-reduced-motion: لا رفع أو انتقال متحرك في العناصر الجديدة؛ الإحصاءات موجودة. حجب GSAP وReact Bits: المحتوى ظاهر والإحصاءات الاحتياطية تقرأ البيانات الحقيقية.
- صفحات accessories/product/checkout/auth تفتح دون تحميل page-theme.css أو تفعيل body.pt-page. لم تتغير ملفات style.css أو data/* أو admin-* أو منطق checkout أو ملفات الهيدر والهيرو والكروت ضمن هذه المهمة.
- npm run build:fx نجح لتحديث js/vendor/rb-islands.js بعد تغيير Stats. لا مكتبات جديدة. node --check وفحص CSS بواسطة esbuild نجحا.

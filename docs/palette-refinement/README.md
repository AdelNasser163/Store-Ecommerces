# تنسيق الأقسام وصفحة المنتجات

## ما تغير

- خلفية موحدة #f4f6f8 بدل التوهجات الملونة الموزعة، وسطح أبيض هادئ مشترك للأقسام والآراء وبطاقات الأقسام والعروض.
- إزالة الإطار الأبيض الكبير المحيط بفئة Shop by Category؛ أصبحت البطاقات جزءًا من نفس شبكة الصفحة بدل قسم داخل صندوق مختلف.
- بطاقتا PC وKitchen أصبحتا فاتحتين بنفس الحدود والظل والخطوط؛ الاختلاف الداكن محفوظ لـFlash Deals والنشرة والفوتر. لا تغيير للروابط أو النصوص أو العروض.
- تدرج كحلي واحد مشترك لـFlash Deals والنشرة ومقدمة المنتجات؛ لا أزرق فاقع أو أخضر مصفر في الخلفيات الكبيرة. مسافات الأقسام أصبحت 80px على الديسكتوب و48px على الموبايل.
- مقدمة صفحة المنتجات أصبحت بانر كحلي مع عنوان أبيض ومسار أخضر فاتح وزخرفة دائرية بسيطة. أعيد تنسيق شريط الأدوات والفلاتر والاختيارات والعدادات والترقيم بنفس أسطح وحدود الهوية.
- أخضر التفاعل يشمل سلايدر السعر وحالات التحديد وأزرار الفلترة بدل بقايا الألوان القديمة. الأحمر ما زال مستخدمًا في شارات الخصم الخاصة بالكارت.

الهيدر والهيرو وقالب الكروت ومنطق المنتجات والسلة لم تتغير في هذه الجولة. ملفات HTML تغيرت فقط لتحديث نسخ CSS في المتصفح. باقي صفحات المشروع لم تبدأ بعد.

## التحقق واللقطات

results.json: الرئيسية والمنتجات باللغتين على 1440 و820 و390؛ فحص السلة والدرج والفرز ولوحة الفلاتر، تطابق اسم رابط المنتجات مع وجهته، ظهور الكروت بعد التمرير، وعدم وجود سكرول أفقي. سجل أخطاء المتصفح مرفق لكل حالة.

catalog-*.png لقطات أعلى صفحة المنتجات؛ index-*-full.png وaccessories-*-full.png للصفحات كاملة. جزيئات الهيرو أخفيت مؤقتًا في لقطات الصفحة الرئيسية فقط لتجنب عيب رسم Canvas في الالتقاط الكامل بالمتصفح الآلي؛ لا يوجد تعديل للجزيئات في الموقع.

لا push، والتعديلات السابقة غير المتعلقة بالمرحلة محفوظة خارج الـcommit.
